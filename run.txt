CATATAN KONFIGURASI IP SERVER
MENJALANKAN MENGGUNAKAN 4 DEVICE

SERVER
Laptop yang menjadi SERVER di code server_parkir.py :
IP_SERVER = "0.0.0.0"
dan di semua code client 1-4.py menggunakan localhost atau ip sendiri yang jadi server


CLIENT
untuk laptop client semua code client 1-4.py dan server_parkir.py menggunakan :
IP_SERVER = "isi dengan IP temanmu yang jadi server"


Semua client harus menggunakan IP server yang sama agar terhubung ke satu server 
dan menggunakan data parkir yang sama.


URUTAN DEMO

Kendaraan masuk
→ Server menyimpan data
→ Petugas melihat slot terisi
→ Kendaraan keluar
→ Server mengosongkan slot
→ Manajer melihat transaksi dan pendapatan


CATATAN
-Server harus tetap berjalan selama semua client digunakan.
-Semua client menggunakan IP Server yang sama.
-Semua device harus berada dalam jaringan Wi-Fi yang sama.
-IP Server diperoleh dari ipconfig pada Device 1.


MENJALANKAN MENGGUNAKAN 1 DEVICE
Jika semua program dijalankan pada satu laptop, di code server_parkir.py gunakan:
IP_SERVER = "localhost"

Semua code client dapat menggunakan:
IP_SERVER = "localhost"
